# ImageVault 文档

## 项目概述

ImageVault 是一个前后端分离的在线图库 Web 应用，用于上传、浏览、预览、标注和整理本地图片。

**目标用户**: 需要快速整理个人照片、截图或设计素材的个人用户。

**核心价值**:
- 一次上传多张图片，立即形成可浏览图库
- 灯箱大图预览，支持缩放、拖拽与键盘切换
- 标签、搜索与删除，形成轻量级图片管理闭环

## 技术选型

| 类别 | 选择 | 理由 |
|------|------|------|
| 前端 | Vue 3 + Vite | 组件化开发，开发服务器启动快，便于预览 |
| 后端 | FastAPI | 异步文件上传友好，接口定义清晰 |
| 数据存储 | SQLite | 单用户无需额外部署数据库 |
| 文件存储 | 本地磁盘 | 原图与缩略图分开存放，实现简单 |
| 图片处理 | Pillow | 生成缩略图，统一预览尺寸 |
| 运行环境 | 浏览器 + Python 3 | 前端走 Vite 开发服务器，后端由 Uvicorn 托管 |

## 核心功能

### 图片上传
- **目的**: 把本地图片纳入图库
- **描述**: 支持拖拽或选择多张图片上传，写入原图、生成缩略图，并保存文件名、尺寸、大小与标签

### 网格图库
- **目的**: 快速浏览全部图片
- **描述**: 以缩略图网格展示，支持按页加载，显示标签摘要与图片数量

### 灯箱预览
- **目的**: 查看原图细节
- **描述**: 点击缩略图进入全屏灯箱，支持缩放、拖拽、上一张/下一张、键盘操作

### 分类标签
- **目的**: 给图片归类
- **描述**: 上传时可填写标签，详情中可增删标签，图库可按标签筛选

### 搜索筛选
- **目的**: 按文件名或标签找到目标图片
- **描述**: 顶部搜索框对文件名与标签做模糊匹配，可与标签筛选叠加

### 删除管理
- **目的**: 清理不需要的图片
- **描述**: 支持单张删除与多选批量删除，同时移除数据库记录、原图与缩略图

### 首页
- **目的**: 用广告与分类卡片引导浏览
- **描述**: 顶部为可滚动的广告轮播，下方为三列分类卡片，底部为「首页 / 分类」双标签栏

### 分类页
- **目的**: 按分类浏览素材
- **描述**: 左侧为分类名称栏，右侧为当前分类的图片列表，支持搜索与分页，底部保留标签栏

### 广告图管理
- **目的**: 运营首页顶部轮播
- **描述**: 后台可批量上传广告图，设置标题、跳转链接、排序与启用状态

### 素材上传后台
- **目的**: 集中完成分类、上传与素材维护
- **描述**: 独立后台区域，顶部为汉堡菜单侧边栏与「素材上传后台」标题，包含数据看板、分类管理、素材上传、素材管理与回收站
